6  Panels

A plot can be one set of axes or a grid of them, and which you get is never chosen directly. A leaf pose draws one panel, however many layers it holds and whatever columns they name. More panels come from three places:

  • pj/facet over columns – a panel per column, or per pair of columns.

  • pj/facet over the categories of a column – a panel per category.

  • pj/arrange – a panel per pose given to it.

This chapter shows each, and how they combine. Faceting and Composition teach each in depth.

Read Poses first for what a leaf is.

(ns plotje-book.panels
  (:require
   ;; Kindly -- notebook rendering protocol
   [scicloj.kindly.v4.kind :as kind]
   ;; Plotje -- composable plotting
   [scicloj.plotje.api :as pj]))
(def measurements
  {:height  [1 2 3 4]
   :weight  [1 2 3 4]
   :depth   [2 3 4 5]
   :species ["a" "a" "b" "b"]})

The panel of a leaf pose

A pose built from one dataset with one mapping is a single leaf, and draws a single panel:

(-> measurements
    (pj/lay-point :height :weight))

Adding a layer does not add a panel. The layers of a pose share its axes and paint over one another, which is the point of them:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/lay-line :height :weight))

That holds for a layer naming other columns too. Its columns are drawn against the axes the panel already has, each axis covers every column drawn on it and is titled by all of them, and each layer takes a colour and a legend entry naming its columns:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/lay-point :depth :weight))
Notestdout 
Note: pj/lay-point names :depth on :x where this pose draws :height on :x, and is drawn on the same panel; in 0.16.1 it was given a panel of its own. For a panel per column, write (pj/facet pose {:x [:height :depth]}), or arrange separate poses with pj/arrange.

How the colour of each layer is decided – a colour it specifies, a :color on the pose, or a layer coloured by a column – is in Inference Rules.

The panel’s columns

A pj/lay-* call keeps its columns on its own layer, so a pose built by such calls has no mapping of its own. The panel still has columns: on each axis, the column the pose names, and where the pose names none there, the column of the first layer that names one. A layer that names no columns reads both of the panel’s columns:

(-> measurements
    (pj/lay-point :height :weight)
    pj/lay-smooth)

The layer that names no columns may be written first. A pj/lay-* call does not read the data’s columns when it is called; the layer is given its columns when the pose is drawn, so a later call may name them:

(-> measurements
    pj/lay-smooth
    (pj/lay-point :height :weight))

A layer that names one column reads the panel’s column on the other axis, where its layer type draws from two columns. The line below names :depth on :y and is drawn against the panel’s :height:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/lay-line {:y :depth}))
Notestdout 
Note: pj/lay-line names :depth on :y where this pose draws :weight on :y, and is drawn on the same panel; in 0.16.1 it was given a panel of its own. For a panel per column, write (pj/facet pose {:y [:weight :depth]}), or arrange separate poses with pj/arrange.

A layer type that can draw from one column is not given a second column. A rug draws from one column, so the rug below marks :depth along the :x axis and reads no :y:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/lay-rug {:x :depth}))
Notestdout 
Note: pj/lay-rug names :depth on :x where this pose draws :height on :x, and is drawn on the same panel; in 0.16.1 it was given a panel of its own. For a panel per column, write (pj/facet pose {:x [:height :depth]}), or arrange separate poses with pj/arrange.

A panel per column

To draw the two columns apart, split the pose over them with pj/facet. Each layer naming one of the columns is drawn only in that column’s panel:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/lay-point :depth :weight)
    (pj/facet {:x [:height :depth]}))
Notestdout 
Note: pj/lay-point names :depth on :x where this pose draws :height on :x, and is drawn on the same panel; in 0.16.1 it was given a panel of its own. For a panel per column, write (pj/facet pose {:x [:height :depth]}), or arrange separate poses with pj/arrange.

The cells of a facet over columns are made from the panel’s columns, and the facet replaces the column on the axis it names. Below, the point layer names :weight, so it is drawn in the :weight panel. The :depth panel keeps the panel’s :height on :x. No layer names :depth, so that panel draws the layer the data chooses for :height and :depth, which is a scatter too:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/facet {:y [:weight :depth]}))

Where one layer is meant for every column, name the columns in the facet alone. The panels share the axis they agree about, :weight, and title it once:

(-> measurements
    (pj/pose {:y :weight})
    pj/lay-point
    (pj/facet {:x [:height :depth]}))

A matrix of columns

A facet over columns can cross a list of columns with itself: {:col {:x columns} :row {:y columns}} draws a panel for every pair of columns, the columns across drawn on :x and the same columns down drawn on :y. A layer added after it is drawn in the panels whose columns it draws, and a panel with the same column on both axes draws a histogram:

(-> measurements
    (pj/facet {:col {:x [:height :weight :depth]}
              :row {:y [:height :weight :depth]}})
    pj/lay-point)

pj/matrix writes that facet from the list of columns:

(-> measurements
    (pj/matrix [:height :weight :depth])
    pj/lay-point)

A panel per category

A facet over the categories of a column draws one panel per category, each drawing the rows of its category. Two species give two panels:

(-> measurements
    (pj/lay-point :height :weight)
    (pj/facet :species))

The panels share both axes, so the categories can be read against each other: species “a” spans 1 to 2 on :height and species “b” 3 to 4, and both panels run from below 1 to above 4.

Arranging poses side by side

pj/arrange takes finished poses and makes each one a cell of a single composite:

(pj/arrange [(pj/lay-point measurements :height :weight)
             (pj/lay-point measurements :depth :weight)])

Each pose above carries the dataset, so each cell computes its own axes and titles weight beside its own panel. Given the dataset first, pj/arrange makes its cells parts of one dataset. Cells that draw the same column on an axis then share that axis, titled once beside the grid, as the panels of a facet are:

(-> (pj/arrange measurements [{:x :height :y :weight}
                              {:x :depth :y :weight}])
    pj/lay-point)

Composition gives the rule for which cells share an axis, and how :share-scales changes it.

A composite pose can also be written directly, which Composition covers. It is the same structure pj/arrange builds.

Cells that filter the data

A cell of pj/arrange may hold :where, a map from a column to a value, and draws only the rows that match. The cell is what (pj/pose nil {:where {:species "a"}}) writes, as any cell is what one argument after the data is to pj/pose. Cells that split one dataset by the values of one column draw what pj/facet draws over that column:

(-> measurements
    (pj/pose {:x :height :y :weight})
    (pj/arrange [{:where {:species "a"}}
                 {:where {:species "b"}}])
    pj/lay-point)

Faceting compares the two forms, and Pose Rules says how a filter on the pose combines with a cell’s.

Combining facets and arrangements

Columns and categories cross in one pj/facet call, the categories across and the columns down. Each entry under :col and :row is one of the two kinds of facet, as in the matrix above:

(-> measurements
    (pj/pose {:x :height})
    pj/lay-point
    (pj/facet {:col :species :row {:y [:weight :depth]}}))

Two pj/facet calls, one over the categories and one over the columns, write the same grid, in either order:

(-> measurements
    (pj/pose {:x :height})
    pj/lay-point
    (pj/facet {:y [:weight :depth]})
    (pj/facet :species))

:col and :row are aesthetics, so a facet written on an arranged pose reaches every cell:

(-> (pj/arrange [(pj/pose measurements :height :weight)
                 (pj/pose measurements :depth :weight)])
    (pj/lay-point)
    (pj/facet :species))
