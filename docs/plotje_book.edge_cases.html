39  Edge Cases

This chapter tests how Plotje handles unusual or boundary inputs – missing values, extreme numbers, degenerate datasets, and uncommon configurations.

(ns plotje-book.edge-cases
  (:require
   ;; Rdatasets -- standard datasets
   [scicloj.metamorph.ml.rdatasets :as rdatasets]
   ;; Tablecloth -- dataset manipulation
   [tablecloth.api :as tc]
   ;; Kindly -- notebook rendering protocol
   [scicloj.kindly.v4.kind :as kind]
   ;; Plotje -- composable plotting
   [scicloj.plotje.api :as pj]
   ;; Fastmath -- random number generation
   [fastmath.random :as rng]
   ;; Java-time -- idiomatic date/time construction
   [java-time.api :as jt]
   ;; dtype-next datetime -- vectorized temporal arithmetic
   [tech.v3.datatype.datetime :as dt-dt]
   ;; dtype-next core -- const-reader for temporal sequences
   [tech.v3.datatype :as dtype]))

Data Shape

Missing Data

Rows with nil values are dropped before rendering.

(def with-missing
  {:x [1 2 nil 4 5 nil 7]
   :y [3 nil 5 6 nil 8 9]})
(-> with-missing
    (pj/lay-point :x :y))

Infinite Values

Rows with Double/POSITIVE_INFINITY or Double/NEGATIVE_INFINITY are filtered automatically with a warning – similar to log-scale filtering.

(def with-infinity
  {:x [1 2 3 4 5]
   :y [10.0 Double/POSITIVE_INFINITY 30.0 Double/NEGATIVE_INFINITY 50.0]})
(-> with-infinity
    (pj/lay-point :x :y))

Single Point

A lone data point should render without errors.

(-> {:x [3] :y [7]}
    (pj/lay-point :x :y))

Two Points with Regression

Regression requires at least 3 points. With only 2, the line is omitted and the points still render.

(-> {:x [1 10] :y [5 50]}
    (pj/lay-point :x :y)
    (pj/lay-smooth {:stat :linear-model}))

Three Points with Regression

With 3 points, the regression line appears.

(-> {:x [1 5 10] :y [5 25 50]}
    (pj/lay-point :x :y)
    (pj/lay-smooth {:stat :linear-model}))

Constant X

All x values are the same – the plot should still render.

(-> {:x [5 5 5 5 5] :y [1 2 3 4 5]}
    (pj/lay-point :x :y))

Constant Y

All y values are the same.

(-> {:x [1 2 3 4 5] :y [3 3 3 3 3]}
    (pj/lay-point :x :y))

Numeric Range

Negative Values

Data spanning positive and negative values.

(-> {:x [-5 -3 0 3 5] :y [-2 4 0 -4 2]}
    (pj/lay-point :x :y))

Very Large Values

(-> {:x [1e6 2e6 3e6] :y [1e9 2e9 3e9]}
    (pj/lay-point :x :y))

Very Small Values

(-> {:x [0.001 0.002 0.003] :y [0.0001 0.0002 0.0003]}
    (pj/lay-point :x :y))

Large Dataset

1000 random points, colored by group.

(def large-data
  (let [r (rng/rng :jdk 42)]
    {:x (repeatedly 1000 #(rng/drandom r))
     :y (repeatedly 1000 #(rng/drandom r))
     :group (repeatedly 1000 #([:a :b :c] (rng/irandom r 3)))}))
(-> large-data
    (pj/lay-point :x :y {:color :group}))

Many Categories

A bar chart with 12 categories.

(-> (let [r (rng/rng :jdk 99)]
      {:category (map #(keyword (str "cat-" %)) (range 12))
       :value (repeatedly 12 #(+ 10 (rng/irandom r 90)))})
    (pj/lay-bar :category :value))

Computed Columns

Derive a new column and plot it.

(-> (rdatasets/datasets-iris)
    (tc/map-columns :sepal-ratio [:sepal-length :sepal-width] /)
    (pj/lay-point :sepal-length :sepal-ratio {:color :species})
    (pj/options {:title "Sepal Length/Width Ratio"}))

Filtered Subset

Plot only one species.

(-> (rdatasets/datasets-iris)
    (tc/select-rows #(= "setosa" (% :species)))
    (pj/lay-point :sepal-length :sepal-width)
    (pj/lay-smooth {:stat :linear-model})
    (pj/options {:title "Setosa Only"}))

Position and Layout

Stacked bar – single group

Stack with only one color value, so nothing is stacked.

(-> {:category ["a" "b" "c"]
     :count [10 20 15]}
    (pj/lay-bar :category :count {:position :stack}))

Dodge – missing category in one group

Group “g1” has data for “a” and “b”, but “g2” only has “a”. Dodge should still align correctly.

(-> {:x ["a" "b" "a"]
     :g ["g1" "g1" "g2"]}
    (pj/lay-bar :x {:color :g}))

Fill – zero count category

One group has zero count for a category. Fill should handle the zero without error.

(-> {:x ["a" "a" "b" "b" "b"]
     :g ["g1" "g2" "g1" "g1" "g1"]}
    (pj/lay-bar :x {:position :fill :color :g}))

A shift on a scatter

:dx and :dy on continuous data – shifts points without error.

(-> (rdatasets/datasets-iris)
    (pj/lay-point :sepal-length :sepal-width {:dx 0.1 :dy -0.05}))

Confidence ribbon – few rows

Linear regression with :confidence-band true on exactly 3 points (the minimum for a linear model).

(-> {:x [1 2 3] :y [2 4 5]}
    (pj/lay-point :x :y)
    (pj/lay-smooth {:stat :linear-model :confidence-band true}))

Stacked area – single series

Stack with a single color group – should render as a plain area.

(-> (let [r (rng/rng :jdk 55)]
      {:x (range 10)
       :y (repeatedly 10 #(rng/irandom r 20))})
    (pj/lay-area :x :y {:position :stack}))

Scale and Coordinate

Log scale with clean powers of 10

(-> {:x [1 10 100 1000 10000]
     :y [2 20 200 2000 20000]}
    (pj/lay-point :x :y)
    (pj/scale :x :log)
    (pj/scale :y :log))

Log scale spanning decimals to large values

(-> {:x [0.001 0.01 0.1 1 10 100]
     :y [1 2 3 4 5 6]}
    (pj/lay-point :x :y)
    (pj/scale :x :log))

Log scale with non-positive values

Non-positive values are filtered on log-scaled axes, since log requires positive inputs. Here x includes 0 and -1:

(-> {:x [0 -1 1 10 100] :y [1 2 3 4 5]}
    (pj/lay-point :x :y)
    (pj/scale :x :log))

Continuous color – constant value

All points have the same numeric color value. The gradient should still render and not divide by zero.

(-> {:x [1 2 3] :y [4 5 6] :c [5 5 5]}
    (pj/lay-point :x :y {:color :c}))

Diverging color with midpoint at zero

(-> {:x (range 20)
     :y (map #(- % 10) (range 20))
     :val (map #(- % 10.0) (range 20))}
    (pj/lay-point :x :y {:color :val})
    (pj/options {:color-range :diverging :color-midpoint 0}))

Dates with very narrow range (two days apart)

(-> {:date [(jt/local-date 2025 1 1)
            (jt/local-date 2025 1 2)]
     :val [10 20]}
    (pj/lay-point :date :val))

Sub-day precision (LocalDateTime spanning hours)

LocalDateTime values preserve sub-day precision. Tick labels show HH:MM format when the range is less than a day.

(-> {:time (dt-dt/plus-temporal-amount
            (dtype/const-reader (jt/local-date-time 2025 3 15 8 0) 24)
            (map #(* (long %) 15) (range 24)) :minutes)
     :value (map #(+ 18.0 (* 4.0 (Math/sin (* % 0.3)))) (range 24))}
    (pj/lay-line :time :value)
    pj/lay-point)

Instant with sub-day precision

java.time.Instant values are converted to LocalDateTime (UTC) for calendar-aware tick formatting. Tick labels show hours when the range spans less than a day.

(-> {:time (dt-dt/plus-temporal-amount
            (dtype/const-reader (jt/instant 1750003200000) 12)
            (range 12) :hours)
     :temp (map #(+ 20.0 (* 5.0 (Math/sin (* % 0.5)))) (range 12))}
    (pj/lay-line :time :temp)
    pj/lay-point)

Multi-year date range

With a date range spanning several years, tick labels show year values.

(-> {:date (dt-dt/plus-temporal-amount
            (dtype/const-reader (jt/local-date 2020 1 1) 20)
            (map #(* (long %) 120) (range 20)) :days)
     :value (map #(+ 100 (* 50 (Math/sin (* % 0.4)))) (range 20))}
    (pj/lay-line :date :value)
    pj/lay-point)

Polar with many categories

(-> (let [r (rng/rng :jdk 12)]
      {:cat (map #(str "cat-" %) (range 12))
       :val (repeatedly 12 #(rng/irandom r 100))})
    (pj/lay-bar :cat :val)
    (pj/coord :polar))

Log scale + coord flip combined

When log scale and coord flip are both applied, the panel should have log ticks on the (now vertical) axis and the domain should reflect the flipped layout.

(-> {:x [1 10 100 1000] :y [2 4 8 16]}
    (pj/lay-point :x :y)
    (pj/scale :x :log)
    (pj/coord :flip))

Scale with explicit domain

(-> (rdatasets/datasets-iris)
    (pj/lay-point :sepal-length :sepal-width)
    (pj/scale :y {:domain [0 6]}))

A size scale anchored at zero, on data holding a zero

:from-zero makes the area proportional to the value, so a value of zero gives a radius of zero and that mark is not visible. This is the correct result for a proportional scale, and ggplot2’s scale_size_area behaves the same way, but a row can disappear without anything being wrong.

(-> {:x [1 2 3] :y [1 2 3] :n [0 5 10]}
    (pj/lay-point :x :y {:size :n})
    (pj/scale :size {:from-zero true}))

A size scale anchored at zero, on data holding a negative

Anchored at zero, the distance from zero decides the size, so a value of -5 is drawn the size a value of 5 is drawn. The mark stays on the panel and keeps its place on the axis; only its size stops distinguishing the two directions. Where the sign matters, map it to another aesthetic – :color splits the two apart.

(-> {:x [1 2 3] :y [1 2 3] :n [-5 5 10]}
    (pj/lay-point :x :y {:size :n})
    (pj/scale :size {:from-zero true}))

A size domain with no spread

When every value is equal there is nothing to compare, so every mark is drawn halfway across the domain rather than at one of its ends. Halfway is read through the scale’s own spread method (:by – how the values spread across the range), so a constant column and a nearly-constant one are drawn alike.

(-> {:x [1 2 3] :y [1 2 3] :n [5 5 5]}
    (pj/lay-point :x :y {:size :n}))

A size range written backwards

[8 2] runs from large to small. This reverses the encoding rather than raising an error: the largest value is drawn smallest.

(-> {:x [1 2 3] :y [1 2 3] :n [1 5 10]}
    (pj/lay-point :x :y {:size :n})
    (pj/scale :size {:range [8 2]}))

Fixed aspect ratio with extreme domain ratio

(-> {:x (range 100) :y (range 0 10 0.1)}
    (pj/lay-point :x :y)
    (pj/coord :fixed))

Full grid – a matrix of columns

A facet crossing a list of columns with itself draws a panel for every pair of the columns – the pose pj/matrix returns, so (pj/matrix data [:sepal-length :sepal-width :petal-length]) draws the same grid. Each column is named once above its column of panels and once beside its row of panels, and a panel with one column on both axes draws a histogram of that column.

(-> (rdatasets/datasets-iris)
    (pj/pose {:color :species})
    (pj/facet {:col {:x [:sepal-length :sepal-width :petal-length]}
              :row {:y [:sepal-length :sepal-width :petal-length]}}))

Error Messages

Plotje reports an error for these common mistakes.

Non-existent column

(try
  (-> {:x [1 2 3] :y [4 5 6]}
      (pj/lay-point :nonexistent :y)
      pj/plot)
  (catch Exception e
    (ex-message e)))
"Column :nonexistent (from :x) not found in dataset. Available: (:x :y) To place the mark at :nonexistent itself rather than read a column, write {:x {:value :nonexistent}}."

Non-existent color column

(try
  (-> {:x [1 2 3] :y [4 5 6]}
      (pj/lay-point :x :y {:color :bogus})
      pj/plot)
  (catch Exception e
    (ex-message e)))
"Column :bogus (from :color) not found in dataset. Available: (:x :y)"

A layer with its own :data that lacks the panel’s columns

A layer that names no columns reads the panel’s columns. When the layer carries its own :data and that data lacks one of them, the error names the column and says to set the axis on the layer call, to a column of the layer’s data. This error covers a second layer attached with its own dataset whose columns do not match the panel’s axes, a pattern common in ggplot2.

(try
  (-> (tc/dataset {:fitted [1 2 3] :residual [1 2 3]})
      (pj/lay-point :fitted :residual)
      (pj/lay-text {:data (tc/dataset {:x    [1 2 3]
                                       :y    [1 2 3]
                                       :text [:a :b :c]})})
      pj/plan)
  (catch clojure.lang.ExceptionInfo e
    (ex-message e)))
"pj/lay-text :y :residual, the panel's column or the layer's own, names a column absent from this layer's :data. Available columns: [:text :x :y]. Set :y on the layer call to a column that exists in :data."

Unsupported polar mark

(try
  (-> {:x [1 2 3] :y [4 5 6]}
      (pj/lay-line :x :y)
      (pj/coord :polar)
      pj/plot)
  (catch Exception e
    (ex-message e)))
"Mark :line is not supported with polar coordinates. Supported polar marks: (:bar :point :rect :rug :text)"

Mismatched mark and stat

(try
  (-> {:x [1 2 3]}
      (pj/pose :x)
      (pj/lay {:mark :boxplot :stat :bin})
      pj/plot)
  (catch Exception e
    (ex-message e)))
"Stat result for :boxplot mark must contain :boxes, got keys: (:bins :max-count :x-domain :y-domain)"

A layer naming a column no cell of an arrangement draws

A pj/lay-* call on an arrangement adds no cell: a layer that fits no cell is drawn in every cell. Where the cells hold no layers of their own and the layer names a column that no cell draws, each cell would draw only that layer and leave its own columns unread, so drawing the pose reports an error. The error names the columns, and suggests adding the column to the cells or drawing the layer on a pose of its own beside the others with pj/arrange:

(try
  (-> (rdatasets/ggplot2-mpg)
      (pj/arrange [{:x :displ :y :hwy} {:x :displ :y :cty}])
      (pj/lay-point :cty :hwy)
      pj/plan)
  (catch clojure.lang.ExceptionInfo e
    (ex-message e)))
"pj/lay-point names :cty on :x, and no panel draws it: the panels draw :displ on :x. Add :cty to the :x columns the panels are made from -- the facet's, or the cells given to pj/arrange -- and leave :x off the layer, or draw the layer on a pose of its own and put the two side by side with pj/arrange. A layer naming no column is drawn in every panel."

A second column given to a layer type that draws from one column

A histogram, a density and a rug each draw from one column. Naming a second column, in the arguments or in the mapping, reports an error:

(try
  (-> {:x [1 2 3] :y [4 5 6]}
      (pj/lay-histogram :x :y))
  (catch clojure.lang.ExceptionInfo e
    (ex-message e)))
"pj/lay-histogram draws from one column, and was given :x on :x and :y on :y. Name one column; to draw the layer on its side, name the column on :y, as in (pj/lay-histogram data {:y :x})."

A bar is not among these layer types: (pj/lay-bar data :x :y) draws a bar for each row, whose length is that row’s :y value. To draw a histogram on its side, name the column on :y in the layer’s mapping:

(pj/lay-histogram (rdatasets/datasets-iris) {:y :sepal-length})
