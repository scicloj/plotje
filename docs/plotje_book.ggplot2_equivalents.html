31  ggplot2 Equivalents

A reader who knows ggplot2 arrives with a plot already in mind and a function name for each part of it. The question is what that function is called in Plotje, and the answers are taught across several chapters, each in the context of its own topic. This chapter collects them: each row gives a ggplot2 spelling, the Plotje spelling, and the section of the book that teaches it. Rows with no Plotje spelling are listed at the end.

The examples use the iris and mpg datasets from the RDatasets collection.

(ns plotje-book.ggplot2-equivalents
  (:require
   ;; Rdatasets -- standard datasets
   [scicloj.metamorph.ml.rdatasets :as rdatasets]
   ;; Tablecloth -- dataset manipulation
   [tablecloth.api :as tc]
   ;; Kindly -- notebook rendering protocol
   [scicloj.kindly.v4.kind :as kind]
   ;; Plotje -- composable plotting
   [scicloj.plotje.api :as pj]))

Mappings and layers

ggplot2 Plotje Taught in
ggplot(df, aes(x = a, y = b)) (pj/pose df :a :b), or (pj/pose df {:x :a :y :b}) Core Concepts
+ geom_point() pj/lay-point Core Concepts
+ geom_smooth(method = "lm") (pj/lay-smooth {:stat :linear-model}) Relationships
+ geom_point(data = df2) (pj/lay-point {:data df2}) Core Concepts
+ geom_point(aes(x = c, y = d)), a layer on other columns (pj/lay-point :c :d), drawn on the same panel, each axis titled by both columns Panels
pivot_longer() then aes(color = name) (pj/lay-line df :x [:a :b]), a series Series

Where the layers of a panel draw different columns and no layer is colored by a column, Plotje gives each layer a color and a legend entry naming its columns; ggplot2 draws both layers in one color with no legend.

A pose with a point layer and a linear-model smooth, the Plotje spelling of ggplot(iris, aes(Sepal.Length, Sepal.Width)) + geom_point() + geom_smooth(method = "lm"):

(-> (rdatasets/datasets-iris)
    (pj/pose :sepal-length :sepal-width)
    pj/lay-point
    (pj/lay-smooth {:stat :linear-model}))

Under a facet, ggplot2 divides a layer’s data = among the panels by the facet column, as it divides the plot’s data. Plotje divides the pose’s data only: a layer that carries :data of its own is drawn whole in every panel. Here the regression fitted to the setosa rows is drawn in each of the three species panels, where ggplot2 4.0.0 draws it in the setosa panel alone:

(-> (rdatasets/datasets-iris)
    (pj/pose :sepal-length :sepal-width)
    pj/lay-point
    (pj/lay-smooth {:stat :linear-model
                    :data (tc/select-rows (rdatasets/datasets-iris)
                                          #(= "setosa" (:species %)))})
    (pj/facet :species))

For layer data that differs from panel to panel, build the panels with pj/arrange, as Known Limitations describes.

Scales

ggplot2 Plotje Taught in
+ scale_x_log10() (pj/scale :x :log) Core Concepts, Scales
+ scale_x_reverse() (pj/scale :x {:domain [high low]}), a :domain written high to low Scales
+ expand_limits(y = 0) (pj/scale :y {:include 0}) Scales
+ scale_color_manual(values = ...) (pj/scale :color {:values [...]}) Scales

A log axis and a reversed axis on one plot – the population on a log scale, the area written from high to low:

(-> {:population [1000 5000 50000 200000 1000000 5000000]
     :area [2 8 30 120 500 2100]}
    (pj/lay-point :population :area)
    (pj/scale :x :log)
    (pj/scale :y {:domain [2500 0]}))

:include makes an axis reach a value the data does not:

(-> (rdatasets/datasets-iris)
    (pj/lay-point :sepal-length :sepal-width)
    (pj/scale :y {:include 0}))

Coordinates

ggplot2 Plotje Taught in
+ coord_flip() (pj/coord :flip) Core Concepts
+ coord_fixed() (pj/coord :fixed) Core Concepts
+ coord_polar() (pj/coord :polar) Polar
+ coord_cartesian(ylim = c(3, 3.5)) (pj/scale :y {:domain [3 3.5]}) Scales

ggplot2 has two ways to narrow an axis. coord_cartesian(ylim =) narrows the view and keeps every row, while the scale limits scale_y_continuous(limits =) drop the rows outside them – measured with ggplot2 4.0.0 on iris narrowed to sepal widths from 3 to 3.5, coord_cartesian keeps all 150 rows and the scale limits keep 74. A :domain on an axis behaves as coord_cartesian does, though it is written on the scale. All 150 rows are drawn and clipped at the panel edge:

(-> (rdatasets/datasets-iris)
    (pj/lay-point :sepal-length :sepal-width)
    (pj/scale :y {:domain [3 3.5]}))

Facets and arrangements

ggplot2 Plotje Taught in
+ facet_wrap(~ drv) (pj/facet pose :drv), which draws its panels in one row Faceting
+ facet_wrap(~ class, ncol = 4) (pj/facet pose :class {:cols 4}) Wrapping the panels into rows
+ facet_grid(cyl ~ drv) (pj/facet pose {:col :drv :row :cyl}) Faceting
pivot_longer() then facet_wrap(~ name, scales = "free_y") (pj/facet pose {:y [:a :b]}) A Panel per Column
patchwork’s p1 | p2 (pj/arrange [p1 p2]) Composition
GGally::ggpairs(df, columns = cols) (pj/matrix df cols) Relationships

Faceting’s own table covers the faceting options – free scales, strip labels, margins – in more detail.

A grid of categories, the Plotje spelling of facet_grid(cyl ~ drv):

(-> (rdatasets/ggplot2-mpg)
    (pj/lay-point :displ :hwy)
    (pj/facet {:col :drv :row :cyl}))

Labels and options

ggplot2 Plotje Taught in
+ labs(title = ..., x = ..., y = ...) (pj/options {:title ... :x-label ... :y-label ...}) Customization
+ labs(subtitle = ..., caption = ...) (pj/options {:subtitle ... :caption ...}) Customization
+ labs(color = ...) (pj/options {:color-label ...}) Customization
theme_set(...) pj/set-config! Configuration

Options and Scopes says which of Plotje’s categories – mapping, layer, plot option, configuration – each ggplot2 construct falls in.

(-> (rdatasets/datasets-iris)
    (pj/lay-point :sepal-length :sepal-width {:color :species})
    (pj/options {:title "Iris Sepal Measurements"
                 :x-label "Length (cm)"
                 :y-label "Width (cm)"
                 :color-label "Species"}))

Not available

Some ggplot2 features have no Plotje spelling in this release:

ggplot2 Plotje Taught in
after_stat(count) inside aes() not available; aggregate the data first and map the computed column Known Limitations
aes(linetype = ...) not available; {:stroke-dash [5 5]} on a line layer dashes the whole layer, and no column varies the dashes Known Limitations
scale_x_sqrt() not available; the axis types are :linear, :log and :categorical Known Limitations
position_jitterdodge() not available
facet_grid(scales = "free_y"), one :y per row of panels not available; {:share-scales #{:x}} fits :y to each panel instead Faceting

A square-root axis reports an error that lists the types an axis accepts:

(try
  (-> (rdatasets/datasets-iris)
      (pj/lay-point :sepal-length :sepal-width)
      (pj/scale :x :sqrt)
      pj/plan)
  (catch clojure.lang.ExceptionInfo e
    (ex-message e)))
"Unknown scale type: :sqrt. Supported for :x: [:categorical :linear :log]."
